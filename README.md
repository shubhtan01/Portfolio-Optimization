## 🔍 Overview

This project implements a set of advanced portfolio optimization frameworks to determine the optimal allocation across selected assets. It combines traditional financial models with modern statistical, clustering, and Bayesian techniques to manage risk and enhance portfolio performance.

The end goal is to build a full-stack web-based portfolio management tool that integrates real-time data and user-defined constraints using Django.

---

## 🧠 Models Implemented

### 🔹 Statistical & Optimization Approaches
- Mean-Variance Optimization (MVO)
- Hierarchical Risk Parity (HRP)
- Hierarchical Clustering + MVO
- Hierarchical Clustering + HRP
- Black-Litterman Model
- Black-Litterman + Clustering Hybrid
- MVO + Bayesian Adjustment

---

## 📁 Data Inputs

- Daily historical prices (stocks, indices)
- Financial ratios and valuation metrics
- Macroeconomic indicators (optional)
- User-defined investor views (for Black-Litterman)

---

## ⚙️ Features

- 📈 Dynamic Portfolio Construction
- 🔍 Regime-Based Strategy Switching
- 📊 Risk Metric Tracking (Sharpe, Sortino, Drawdown)
- 🧠 Intelligent Clustering (e.g., K-Means, Hierarchical)
- 🌐 Integration-Ready for Django Dashboard
- 🛡️ Risk Management:  
  - Volatility constraints  
  - Stop-loss rules  
  - Max asset weight bounds
